Hi everyone,

If you've ever needed to recover or verify the RTK base station coordinates used during a flight from an ArduPilot `.tlog` file, I built an open-source Windows app and Python CLI to do it automatically.

**GitHub Repository:** https://github.com/Gourav1997/rtk-base-coordinate-reader

### What it does

* Reads `.tlog` files and extracts `GPS_RTCM_DATA` (message 233).
* Reassembles fragmented MAVLink RTCM packets and validates RTCM3 frames.
* Decodes **RTCM 1005 / 1006** antenna reference positions and converts ECEF to WGS84 latitude, longitude, and ellipsoidal altitude.
* Displays coordinates in a copyable table with first/last UTC receive timestamps, observation counts, and station IDs.
* Plots base locations on Esri satellite imagery.

![RTK Base Coordinate Reader showing the results table and satellite map](https://raw.githubusercontent.com/Gourav1997/rtk-base-coordinate-reader/main/docs/images/rtk-base-reader.png)

*Screenshot uses clearly labeled illustrative demo coordinates, not private flight data.*

You can grab the standalone **RTK-Base-Reader.exe** from the [alpha release](https://github.com/Gourav1997/rtk-base-coordinate-reader/releases/tag/v0.1.0-alpha.1), or run `extract_base.py` from the CLI. The source also includes a one-step dependency installer.

The log must contain recorded `GPS_RTCM_DATA` and valid RTCM 1005/1006 messages. Altitude is ellipsoidal antenna reference point height, not mean sea level. Map imagery needs internet access; log extraction works offline.

The project is licensed under GPLv3. Feedback and bug reports are welcome!
